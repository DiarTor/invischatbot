# InvisChatBot 🤖

InvisChatBot is a Telegram bot that allows users to send **anonymous messages** to each other. It's designed to enable private, discreet communication through Telegram.

## 🔐 Features

- Send messages without revealing your identity.
- Simple and easy to use via Telegram.
